# Working in this repo (app walkthroughs)

One shared tool that records the YouTube walkthrough, Short, captions and screenshots for each app. App code stays in each app's own repo; this repo holds only the tool and per-app settings in `apps/`. Read README.md first.

- UK English everywhere. Discuss and plan with Stuart before changing the tool or a script.
- Always made-up demo data with the "Demo data" badge, phone-size view, Kokoro British AI voice, branded intro and outro cards.
- Outro wording should point to the app's site and, where the app has one, its club and support page.
- Club walkthroughs (club.do30daychallenge.com, club.pocketkarate.com) are recorded the same way, with settings in `apps/` like an app.
- Nothing in `output/`, `.work/` or `apps-code/` is committed.
- When a new app is added, add it to the table in README.md.
- Other repos are listed in the repo index in Stuart's Claude memory.
